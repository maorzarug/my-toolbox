# 🛠️ ToolHub - ארגז הכלים הדיגיטלי

אתר כלים דיגיטליים חינמיים ומתקדמים מבוסס **Python / Flask**:
- **🔄 היפוך טקסט ומקלדת** (כולל תיקון ג'יבריש מקלדת עברית-אנגלית)
- **🟢 מחולל קישורי וואטסאפ מהיר**
- **✍️ ניקוד אוטומטי וידני לעברית**
- **📄 מיזוג קובצי PDF**
- **🖼️ פירוק PDF לתמונות ב-ZIP**
- **🗜️ דחיסת PDF חכמה** (מותאמת במיוחד למסמכים סרוקים ואתרים ממשלתיים - הפחתה של 70%-90% בנפח!)
- **🔄 המרת פורמטי תמונות** (JPG, PNG, WEBP, BMP)
- **📐 שינוי גודל תמונה בפיקסלים מדויקים**
- **🎨 פילטרים ואפקטים לתמונה עם תצוגה מקדימה**
- **⚙️ מערכת ניהול פרסומות מובנית (`/admin`)**

---

## 🚀 איך להריץ את האתר במחשב שלך?

1. **ודא שמותקן Python 3**
2. **התקן את התלויות** (פעם אחת בלבד):
   ```bash
   pip install -r requirements.txt
   ```
3. **הפעל את השרת**:
   ```bash
   python app.py
   ```
4. **פתח את הדפדפן בכתובת**:
   [http://localhost:5000](http://localhost:5000)

---

## ⚙️ מערכת ניהול הפרסומות (`/admin`)

כדי להוסיף, לשנות או לעדכן פרסומות באתר בקלות ובלי לגעת בקוד:
1. היכנס בדפדפן לכתובת: `http://localhost:5000/admin` (או בכתובת הדומיין שלך לאחר פריסה).
2. הזן סיסמת כניסה ראשונית: `admin` (ניתן לשנות את הסיסמה ישירות ממסך הניהול).
3. **בחר את חלון הפרסום שתרצה לעדכן**:
   * **חלון 1 (עליון)**: מופיע בראש כל עמוד.
   * **חלון 2 (תחתון)**: מופיע מתחת לכלי העבודה.
4. **סוג הפרסומת לבחירתך**:
   * **באנר מותאם אישית**: הדבק קישור ישיר לתמונה (Image URL) וקישור לאתר היעד (Link URL).
   * **קוד AdSense / HTML**: הדבק ישירות קוד פרסומת של גוגל או כל רשת שותפים.
5. לחץ **"שמור את כל הגדרות הפרסומות"** – והאתר יתעדכן מיידית בלייב!

## 📁 מבנה הקבצים בפרויקט

```
my-toolbox/
├── app.py                  # קובץ השרת הראשי
├── requirements.txt        # ספריות נדרשות
├── vercel.json             # הגדרות פריסה לענן (Vercel)
├── ads_config.json         # הגדרות הפרסומות והסיסמה
├── icon.png                # אייקון האתר
├── README.md               # מדריך שימוש זה
│
├── services/               # שכבת הלוגיקה העסקית והעיבודים
│   ├── ads_service.py      # ניהול פרסומות
│   ├── pdf_service.py      # דחיסת PDF חכמה, מיזוג והמרה
│   ├── image_service.py    # המרה, שינוי גודל ופילטרים
│   └── nikud_service.py    # ניקוד עברי
│
├── static/                 # קבצים סטטיים
│   ├── css/style.css       # עיצוב האתר (Glassmorphism מודרני)
│   ├── js/                 # קובצי סקריפט לכלים
│   ├── manifest.json       # הגדרות אפליקציה PWA
│   └── icon.png
│
└── templates/              # תבניות ה-HTML
    ├── base.html           # שלד האתר הראשי ואזורי הפרסום
    ├── admin.html          # מסך ניהול הפרסומות
    ├── dashboard.html      # דף הבית
    ├── inverter.html       # היפוך טקסט
    ├── whatsapp.html       # וואטסאפ
    ├── nikud.html          # ניקוד
    ├── pdf_merge.html      # מיזוג PDF
    ├── pdf_to_img.html     # PDF לתמונות
    ├── pdf_compress.html   # דחיסת PDF ממשלתית
    ├── img_convert.html    # המרת תמונות
    ├── img_resize.html     # שינוי גודל
    ├── img_effects.html    # פילטרים
    └── about.html          # אודות
```
